# Asansör Etiketi Mahkemesi

> **Resmî İlan:** Bu depo, kat malikleri kurulunun 47. olağanüstü toplantısında kabul edilen *Asansör İçi Kamu Düzeni Protokolü*nün yazılımla icrasıdır.

Bu proje, asansörde kapıya yaslananları, “bir dakika dur” deyip 14 kat inenleri ve “ben sadece bir kat çıkacağım” diye merdiven kullanmayanları yargılar. Kararlar bağlayıcıdır. İtiraz mercii yoktur. İtiraz etmek isteyen merdiveni kullanır.

## Neden var?

Çünkü asansör bir ulaşım aracı değil, küçük bir cumhuriyettir. Kapı açıldığında anayasa yürürlüğe girer. Bu yazılım o anayasanın yargı organıdır.

## Kurulum

```bash
python3 mahkeme.py
```

Python 3 yeter. Başka bir şey istemez. Asansör de istemez; zaten gelmez.

## Kullanım

Program sana bir senaryo sorar. Sen de gerçeği söylersin. Söylemezsen de söylemiş gibi yargılanırsın. Mahkeme adil değildir; hızlıdır.

Örnek suçlar:
- Kapıya yaslanmak
- 1. kattan 2. kata asansörle çıkmak
- İçeride telefonu yüksek sesle açmak
- “Siz inin ben dururum” deyip durmamak
- Asansörü “kendine ayırmak”
